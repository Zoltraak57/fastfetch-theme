# fastfetch-theme
Inspired By Yozakura-san Chi no Daisakusen Anime

## Install
Arch Linux:
```bash
sudo pacman -S fastfetch
```

Ubuntu/Debian:
```bash
sudo apt install fastfetch
```

Fedora:
```bash
sudo dnf install fastfetch
```

# Installation Theme
```bash
git clone https://github.com/Zoltraak57/fastfetch-theme.git
cd fastfetch-theme
cp -r * ~/.config/fastfetch/
```
